# manlaser — сайт

Сайт услуг manlaser: лазерная очистка металла и антикоррозийная обработка автомобилей (Dinitrol / Mercasol).
Продажа оборудования — отдельный будущий сайт; его контент сохранён в `_source/equipment-site/`.
Vite + чистый JS, GSAP (ScrollTrigger, SplitText), Lenis, Barba.js, Three.js.

> README дополняется по этапам. Сейчас готов **этап 1**: каркас, стиль, навигация, переходы.

## Запуск

Нужен Node.js 20.19+ (установлен 24.x).

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

- `npm run build` — собрать сайт в папку `dist/` (каждая страница — отдельный `index.html`);
- `npm run preview` — посмотреть собранную версию.

## Где что лежит

```
content/          ← ВСЕ тексты и данные (правьте здесь)
  site.json         контакты, телефон, мессенджеры, меню, режим работы, строка про аппараты (equipmentNote)
  pages.json        заголовки и SEO (title/description) страниц
  services.json     услуги: лазерная очистка и антикор
  faq.json          частые вопросы (по группам)
  reviews.json      отзывы (только реальные)
  media.json        места под фото
  blog/*.md         статьи блога
config.js         ← переключатели эффектов: переход, интро, курсор, 3D-сцены
assets/logo.svg   ← логотип (знак + надпись)
public/images/    ← фото
src/templates/    ← HTML-шаблоны страниц и общие компоненты (шапка, футер, формы)
src/css/          ← стили (цвета и шрифты — в tokens.css)
src/js/           ← скрипты (pages/<страница>.js грузится только на своей странице)
build/            ← сборщик страниц из content + шаблонов
```

Правки в `content/` видны сразу после сохранения (страница перезагрузится сама).

### Плейсхолдеры

Всё, чего не было на старых сайтах, помечено в квадратных скобках: `[ЦЕНА]`, `[ОПИСАНИЕ]`, `[РЕКВИЗИТЫ]`.
На сайте такие места подсвечены оранжевым пунктиром. Пометка `⚠` — данные на старых сайтах расходятся, нужно уточнить.

### Фото

Пока фото нет, вместо него стоит заглушка «Место для фото» с описанием, какой кадр нужен.
Полный список мест и их статус: **http://localhost:5173/_photos/** (страница есть только в режиме разработки).

Чтобы добавить фото: положите файл в `public/images/...` и впишите путь в `content/media.json` → `"src": "/images/..."`.

### Телефон и кнопка записи

Телефон и мессенджеры — в `content/site.json → contacts.services`.
Кнопка «Записаться» — одна, плавающая внизу справа. Она прячется, когда на экране есть другая кнопка записи (например, в блоке внизу страницы).

В заголовках можно выделять слово фирменным цветом: `*слово*` (например, `"Очищаем и *защищаем* металл"`).

### Контакты, карта, режим работы, реквизиты

Всё — в `content/site.json`:
- `hours` — режим работы. `open`/`close`/`days` (1 = пн … 7 = вс) — по ним на сайте считается статус «Сейчас открыто / закрыто» (по минскому времени).
- `map.route` и `map.google` — кнопки «Маршрут в Яндекс» / «Google Maps» в блоке «Как нас найти».
- `requisitesList` — строки таблицы реквизитов (сейчас плейсхолдеры).
- Общие вопросы «Запись и контакты» — `content/faq.json`, группа `general`.

## Переходы между страницами

`config.js → transition`:
- `'laser'` — экран прорезает оранжевая лазерная линия с искрами (по умолчанию);
- `'molecules'` — фирменная «молекулярная» сетка из брендбука растёт и рассыпается;
- `'heat'` — шторка из фирменного градиента;
- `'fade'` — простое затемнение.

Ссылки, кнопка «назад» и прямые адреса работают как на обычном сайте (Barba.js подменяет только содержимое).

## 3D-сцена главной и как заменить её видео или кадрами

Закреплённая сцена по скроллу (работает вперёд и назад): ржавая деталь → лазер, ржавчина сгорает, искры →
камера под автомобилем, днище покрывается антикором → логотип собирается из искр.
Подписи к шагам — `content/pages.json → home.scene`. Код сцены — `src/js/scenes/home/`.

`config.js → scenes.home.mode`: `'3d'` (Three.js), `'frames'` (картинки на canvas) или `'video'` (mp4 по скроллу).
Если файлов нет или они не загрузились — показывается статичный экран.

Видео для режима `video` (ключевой кадр в каждом кадре — для плавной перемотки):

```bash
ffmpeg -i source.mp4 -an -vf "scale=1920:-2,fps=30" -c:v libx264 -preset slow -crf 22 -g 1 -pix_fmt yuv420p -movflags +faststart public/video/home.mp4
```

Кадры для режима `frames` (затем впишите их количество в `frames.count`):

```bash
ffmpeg -i source.mp4 -vf "fps=24,scale=1600:-2" -c:v libwebp -quality 72 public/frames/home/frame_%04d.webp
```

## Проверка анимаций

Если в системе включено «уменьшение движения», тяжёлые анимации отключаются.
Принудительно включить их для проверки: добавьте к адресу `?motion=1` (выключить — `?motion=0`).
