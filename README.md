# manlaser.by — сайт продажи и ремонта лазерного оборудования

Ремейк сайта https://manlaser.by/: аппараты CNMLaser (лазерная чистка, сварка 4 в 1, резка, комплектующие), ремонт и диагностика, оплата и доставка.
Тёмный кинематографичный стиль, палитра: оранжевый `#E85002`, голубые `#007BFF` и `#87CEEB`, чёрный и белый.
Парный сайт — услуги (лазерная очистка и антикор): `manlaser-center.by`, отдельный проект.

Vite + чистый JS, GSAP (ScrollTrigger, SplitText), Lenis, Barba.js, Three.js.

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте http://localhost:5180

- `npm run build` — собрать сайт в папку `dist/` (каждая страница — отдельный `index.html`);
- `npm run preview` — посмотреть собранную версию.

## Структура сайта

| Страница | Адрес |
|---|---|
| Главная (3D-сцена с грузовиком) | `/` |
| Оборудование (фильтр по 4 категориям) | `/oborudovanie/`, предвыбор категории — `/oborudovanie/?cat=chistka` |
| Карточка товара | `/oborudovanie/<товар>/`, например `/oborudovanie/man-c01/` |

| Оплата и доставка | `/oplata-i-dostavka/` |

| Блог | `/blog/`, `/blog/<статья>/` |
| О нас → О компании, Контакты, Частые вопросы | `/o-nas/`, `/kontakty/`, `/voprosy/` |

## Где что лежит

```
content/          ← ВСЕ тексты и данные (правьте здесь)
  site.json         контакты, телефон, мессенджеры, меню, режим работы, адрес, реквизиты
  pages.json        заголовки и SEO (title/description) страниц, подписи 3D-сцены
  equipment.json    каталог: категории, товары (цены, наличие, характеристики), преимущества, цифры
  repair.json       ремонт и диагностика
  delivery.json     оплата, доставка, пусконаладка, гарантия
  faq.json          частые вопросы (по группам)
  reviews.json      отзывы покупателей (только реальные)
  media.json        места под фото
  blog/*.md         статьи блога
config.js         ← переключатели: переход между страницами, курсор, отправка заявок, 3D-сцена
assets/logo.svg   ← логотип (знак + надпись)
public/           ← favicon, иконки, картинка для превью ссылок (images/og.jpg), фото
src/templates/    ← HTML-шаблоны страниц и общие компоненты
src/css/          ← стили (цвета и шрифты — tokens.css, каталог и светлая сцена — equipment.css)
src/js/           ← скрипты (pages/<страница>.js грузится только на своей странице)
build/            ← сборщик страниц из content + шаблонов
_source/          ← исходные материалы старого сайта (источник фактов)
```

Правки в `content/` видны сразу после сохранения (страница перезагрузится сама).

### Плейсхолдеры

Всё, чего не было на старом сайте, помечено в квадратных скобках: `[УТОЧНИТЬ]`, `[ЦЕНА]`, `[РЕКВИЗИТЫ]`.
На сайте такие места подсвечены пунктиром. Пометка `⚠` — данные на старом сайте расходятся (например, гарантия на станки и источники Raycus), нужно уточнить.

### Как добавить товар

В `content/equipment.json → products` добавьте объект по образцу соседних: `slug` (адрес страницы), `category` (`chistka`, `svarka`, `rezka` или `komplektuyushchie`), `name`, `type`, `power`, `price`, `stock` («в наличии» / «под заказ»), `warranty`, `media`, `specs` (пары «название — значение»).
Страница товара, карточка в каталоге и пункт в форме заявки появятся сами. Для фото добавьте ключ `product.<…>` в `content/media.json`.

### Фото

Пока фото нет, вместо него стоит заглушка «Место для фото» с описанием, какой кадр нужен.
Полный список мест и их статус: **http://localhost:5180/_photos/** (страница есть только в режиме разработки).

Чтобы добавить фото: положите файл в `public/images/...` (сразу в формате WebP) и впишите путь в `content/media.json` → `"src": "/images/..."`.

### Цвета

Все цвета — переменные в `src/css/tokens.css`: `--accent` (голубой, главный акцент: кнопки, ссылки, свечение), `--orange` (фирменный оранжевый: цены, наличие), `--sky`, `--grad-brand` (градиент белый → небесный → голубой → оранжевый).
Градиент знака — в `assets/logo.svg` и дублируется в `src/js/scenes/truck/sign.js` (3D-вывеска).

### Заявки

Форма на `/zapros/` пока **никуда не отправляется** (`config.js → booking.send: false`): заявка проверяется, показывается экран успеха, текст заявки выводится в консоль. Отправку в Telegram / Viber / почту подключим позже.

## 3D-сцена главной

Только для компьютера. Грузовик на белом фоне в профиль → камера обходит фургон и поворачивается к задним дверцам → дверцы открываются → внутри светящийся логотип manlaser → камера входит в кузов, и сцена плавно переходит в тёмный сайт.
Подписи к шагам — `content/pages.json → home.scene`. Код сцены — `src/js/scenes/truck/` (`truck.js` — модель фургона, `sign.js` — логотип внутри, `index.js` — свет и путь камеры по ключевым кадрам `CAM`).

На телефонах и планшетах (любое сенсорное устройство) 3D не загружается: первый экран — знак manlaser на голубом свечении, при прокрутке поверх него выезжает блок с кнопками. Проверка на компьютере: `?lite=1` / `?lite=0`.

## Проверка анимаций

Если в системе включено «уменьшение движения», тяжёлые анимации и 3D отключаются.
Принудительно включить их для проверки: добавьте к адресу `?motion=1` (выключить — `?motion=0`).
В режиме разработки на главной доступно `document.querySelector('[data-scene-root]').__set(0.63)` — мгновенно показать кадр сцены (0…1).

## Публикация

Автодеплой лежит в `_deploy/deploy.yml` и пока **не подключён**: когда сайт будет готов, перенесите его в `.github/workflows/deploy.yml`, раскомментируйте пуш в `main`, включите Pages (Settings → Pages → Source: GitHub Actions) и подключите домен `manlaser.by`.
