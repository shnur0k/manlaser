## 1. Что это

Сайт услуг компании **manlaser** (г. Пружаны, Беларусь): **лазерная очистка металла** и **антикоррозийная обработка автомобилей** (Dinitrol, Mercasol).

- Язык сайта, интерфейса, комментариев в коде и общения с владельцем — **русский**.
- Стиль: тёмный, кинематографичный, индустриальный, «уровня Awwwards». Чёрный фон, оранжевое свечение, плёночное зерно.
- Сайт пока работает **только локально** у владельца (`npm run dev`), не задеплоен.

### Ключевые решения владельца (не менять без его просьбы)

| Решение | Детали |
|---|---|
| **Только услуги** | Два сайта: этот — услуги; продажа оборудования — будущий отдельный сайт. Контент оборудования сохранён в `_source/equipment-site/`. |
| **Две услуги** | Лазерная очистка и антикор. Резка/сварка удалены. |
| **Про оборудование — одна строка** | `site.json → equipmentNote` («Мы также поставляем и продаём… — manlaser.by»), выводится в «О нас» и в футере. Других упоминаний оборудования нет. |

| **Калькулятор — пункт меню** | Меню: Услуги · Работы · Калькулятор · Блог · О нас. У «О нас» — выпадающее меню. |

### Главное правило контента

**Не выдумывать факты.** Цены, отзывы, реквизиты, описания, которых нет в источниках, — только плейсхолдеры в квадратных скобках: `[ЦЕНА]`, `[ОПИСАНИЕ]`, `[РЕКВИЗИТЫ]`. На сайте они автоматически подсвечиваются оранжевым пунктиром (функция `t()`). Пометка `⚠` — данные в источниках расходятся.

Источники фактов: сохранённые страницы старых сайтов (`manlaser-content/`, `manlaser-contens 2/`), файл владельца с контентом, скриншоты отзывов (`_source/reviews-yandex/`, расшифровано 3 из 9). Старые сайты `.by` из окружения агента **не открываются** (сетевая блокировка), не пытайся их фетчить.

## 2. Команды и окружение

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # → dist/, каждая страница — отдельный index.html
npm run preview
```

- ОС владельца — **Windows**, шелл — PowerShell 5.1. Node установлен в `C:\Program Files\nodejs`. В новых сессиях PowerShell PATH может не содержать node — обнови: `$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')`.
- Для запуска dev-сервера через встроенный браузер есть `.claude/launch.json` (конфигурация `manlaser-dev`).
- Для правки JSON надёжнее node-скрипт (`fs` + `JSON.parse/stringify`), чем PowerShell (кодировки, кавычки, бэктики).
- `Remove-Item` с относительными путями может блокироваться — удаляй через node `fs.unlinkSync('D:/manlaser/...')`.

### Как проверять в браузере

- У владельца в Windows включено «уменьшение движения» → сайт уходит в спокойный режим (без Lenis, без 3D, без появлений). Смотреть эффекты: **`?motion=1`** (запоминается в `sessionStorage` вкладки), выключить — `?motion=0`.
- Встроенный браузер агента рисует **~2 кадра/с** — плавность анимаций там не оценить; проверяй логику через `javascript_tool`.
- В встроенном браузере **не срабатывает IntersectionObserver** — для ленивых вещей нужен запасной путь (проверка при `scroll`).
- Для отладки в dev: `window.__lenis` (экземпляр Lenis), `document.querySelector('[data-scene-root]').__snap()` — мгновенно применить прогресс 3D-сцены без сглаживания.
- Быстрая проверка всех маршрутов: `fetch(url, {headers:{accept:'text/html'}})` из консоли страницы и разбор через `DOMParser`.
- Перед завершением задачи прогоняй `npm run build` и убедись, что нет ошибок.

## 3. Архитектура

### 3.1. Сборка страниц (ключевая особенность)

HTML-файлов страниц в репозитории **нет**. Их генерирует Vite-плагин `build/plugin.js` из **контента** (`content/*.json`, `content/blog/*.md`) и **шаблонов** (`src/templates/**`, JS-функции, возвращающие строки).

```
content/*.json ─┐
assets/logo.svg ─┼─► build/content.js (loadContent) ─► build/routes.js (buildRoutes) ─► src/templates/index.js (renderPage)
content/blog/*.md┘                                                                        └─► layout.js + pages/*.js
```

- **dev:** middleware рендерит страницу на каждый запрос (контент читается заново), прогоняет через `server.transformIndexHtml`, отдаёт с `Cache-Control: no-store`. URL без слэша → 301 на `/…/`. Неизвестный URL → страница 404.
- **build:** в `config()` плагин регистрирует каждую страницу как виртуальный вход `<root>/<url>/index.html` (`resolveId` + `load`), Vite собирает их как обычный MPA. Плюс `404.html`.
- Правка `content/*` или `assets/logo.svg` → полная перезагрузка страницы в браузере.
- Шаблоны импортируются из `vite.config.js` (через `build/plugin.js`) → **правка любого файла шаблонов перезапускает dev-сервер**.

> ⚠ **Подводный камень:** если быстро сделать несколько правок шаблонов подряд (особенно добавить новый импорт или новый файл-партиал), сервер может перезапуститься между ними и закешировать промежуточную версию → страница «Ошибка сборки страницы: X is not defined», хотя код верный. Решение: **перезапустить dev-сервер** (`preview_stop` + `preview_start`). Лучше сначала создавать новые файлы/импорты, потом использовать их.

### 3.3. Шаблоны (`src/templates/`)

- `index.js` — `renderPage(route, content)`: создаёт `ctx` (`c` — весь контент, `site`, `route`, `contact`, `logo`, `logoWord`, `media()`), сбрасывает автонумерацию секций, вызывает шаблон, оборачивает в `layout`.
- Шаблон страницы возвращает строку **или** `{ body, schema?: [], head?, noFooter? }`.
- `layout.js` — `<html>`, meta/OG/canonical, JSON-LD, шапка, мобильное меню, `<main data-barba="container">` (контент + футер), плавающие кнопки, оверлеи. Шапка/меню/плавающие кнопки **вне** контейнера Barba (не перерисовываются при переходах).
- `lib.js` — хелперы. **Всегда** экранируй данные: `esc()` — простой текст, `t()` — текст + подсветка `[плейсхолдеров]` и `⚠`, `rich()` — как `t()`, плюс `*слово*` → оранжевый акцент. `each(arr, fn)` — map+join.
- `components.js` — переиспользуемые блоки: `button`, `eyebrow`, `sectionHead` (автономер «(01)», `align:'center'`, `label:false`), `pageHero` (варианты `compact`, `post`), `serviceFeature`, `serviceCard`, `marquee`, `equipmentNote`, `features`, `steps`, `faq`, `counters`, `reviewCard`, `messengerLinks`, `phoneLink`, `ctaBand`, `section`.
- `media.js` — `media(map, key, opts)`: фото из `content/media.json`; если `src: null` — заглушка «Место для фото» с описанием, какой кадр нужен.
- `schema.js` — Schema.org: `business` (LocalBusiness+AutoRepair на каждой странице), `breadcrumbs`, `service`, `faqPage` (пропускает ответы с плейсхолдерами), `article`, `graph`.
- `partials/` — `header.js` (меню, мегаменю «Услуги», выпадающее «О нас»), `mobile-menu.js`, `footer.js`, `chrome.js` (плавающие кнопки, слой перехода, курсор, тост), `car-map.js` (SVG-силуэты авто для калькулятора: 4 типа, зоны `underbody|arches|sills|cavities`), `contact-blocks.js` (`hoursBlock`, `findUsBlock`, `requisitesBlock`).
- `icons.js` — inline SVG-иконки (`icon(name)`). Новые иконки добавляй сюда.
- Общий код шаблонов и браузера (без DOM): `src/js/lib/contacts.js` (ссылки tel/мессенджеров), `src/js/lib/nav.js` (`activeNavUrl` — какой пункт меню подсветить).

### 3.4. Клиентский JS (`src/js/`)

Точка входа — `main.js` (подключается в `<head>` каждой страницы).

- **Порядок:** env → Lenis → шапка, мегаменю, мобильное меню, плавающие кнопки, курсор, магнитные кнопки → `boot()`: `syncChrome` → ждём шрифты → `mountPage(container)` → `page.start()` → `initRouter()` (Barba).
- **Barba** (`@barba/core`): переходы без перезагрузки. В dev `cacheIgnore` и `prefetchIgnore` включены (иначе после правок видна старая версия). `leave`: закрыть меню → `transition.cover()` → `unmountPage()`. `enter`: обновить `<head>` (`core/head.js`), `syncChrome`, прокрутка (позиция для «назад/вперёд» или якорь из ссылки), `mountPage`, `transition.reveal()`.
- **Якоря при переходе** (`/o-nas/#faq`): Barba теряет хэш — берём его из `data.trigger.hash` и сами прокручиваем.
- **`core/page.js`** — жизненный цикл контейнера. `mountPage` запускает общие модули (появления, магнитные кнопки, наклон карточек, аккордеоны, картинки, фильтр тегов, бегущая строка, статус работы) и **модуль страницы** `src/js/pages/<namespace>.js` (через `import.meta.glob`, грузится только на своей странице). Контракт модуля: `export default (container) => ({ start?, destroy? }) | cleanupFn | null`. `unmountPage` вызывает все cleanup и убивает ScrollTrigger'ы внутри контейнера. **Любые слушатели/таймеры/тикеры обязаны убираться в cleanup.**
- **`core/scroll.js`** — Lenis с собственным циклом (`autoRaf`), синхронизирован с ScrollTrigger. Если браузер рисует < 30 кадров/с — Lenis отключается (иначе колесо мыши «залипает»). `scrollTo(target, {immediate, offset})` — использовать вместо `window.scrollTo`.
- **`core/env.js`** — `reducedMotion` (с учётом `?motion`), `touch`, `lowEnd`, `mobile`.
- **`core/transitions.js`** — переходы `laser` (по умолчанию), `molecules`, `heat`, `fade` (`config.js → transition`).
- **`ui/`** — `header.js` (скрытие при скролле, активный пункт, телефон), `megamenu.js`, `mobile-menu.js`, `floating.js` (одна кнопка записи — прячется, если в кадре другая ссылка на `/zapis/`; скрыта на `/zapis/`), `cursor.js`, `reveal.js`, `interactions.js` (магнит, наклон, аккордеоны, картинки, якоря, фильтр тегов, тост), `marquee.js` (бегущая строка на JS, работает даже при reduced motion, ускоряется от скролла), `hours.js` («Сейчас открыто/закрыто» по `Europe/Minsk`).
- **`lib/`** — `gsap.js` (регистрирует ScrollTrigger + SplitText), `contacts.js`, `nav.js`, `phone.js` (маска `+375 (XX) XXX-XX-XX`, проверка), `booking.js` (`composeMessage`, `sendBooking` — заглушка, пока `booking.send:false`).
- **`fx/sparks.js`** — 2D-искры на canvas (переходы, экран успеха заявки).

### 3.5. 3D-сцена главной

- `src/js/scenes/scroll-scene.js` — общий модуль закреплённой scroll-сцены: пин ScrollTrigger, сглаженный прогресс, подписи `[data-scene-step data-from data-to]`, полоски `[data-scene-bar]`, счётчик `[data-scene-readout]`, выбор режима по `config.js → scenes.<name>.mode`: `'3d' | 'frames' | 'video'`; при reduced motion / без WebGL / при ошибке → статичный режим (`.is-static`).
- `src/js/scenes/home/` — Three.js-сцена (грузится динамически, ~170 КБ gzip): `part.js` (ржавая деталь + лазер, шейдер ржавчины), `car.js` (авто на подъёмнике, шейдер антикора), `logo.js` (3D-логотип из `assets/logo.svg`, сборка из частиц), `index.js` (камера по ключевым кадрам `CAM`, связка прогресса). Общее: `scenes/lib/` (`stage.js` — рендерер, bloom, адаптивное качество; `patch.js` — встраивание GLSL в PBR-материалы; `glsl.js` — шум; `particles.js`).
- Прогресс: 0–0.36 очистка детали → 0.36–0.46 пролёт → 0.46–0.76 антикор днища → 0.76–1 логотип. Подписи шагов — `content/pages.json → home.scene`.
- 3D-объекты по центру кадра; на вертикальных экранах камера отъезжает.

### 3.6. Калькулятор и запись

- `/uslugi/kalkulyator/`: шаблон `calculator()` в `pages/services.js` (разметка формы из `content/prices.json`), логика — `src/js/pages/calculator.js`. Формулы: антикор = Σ зон × коэф. авто × коэф. материала + доп.; очистка = (детали × цена | м² × цена) × коэф. загрязнения, не меньше `minOrder`. Предвыбор услуги: `?service=cleaning|anticor`.
- «Записаться с этим расчётом» → `sessionStorage['ml-calc']` → `/zapis/`.
- `/zapis/`: шаблон `booking()` в `pages/services.js`, логика — `src/js/pages/booking.js` (маска телефона, проверка телефона и согласия, черновик в `localStorage['ml-booking-draft']`, расчёт из калькулятора, анимация успеха). Отправка — `src/js/lib/booking.js`; пока `config.booking.send === false`, заявка никуда не уходит, на экране успеха — жёлтая пометка, текст заявки — в консоли.

## 5. Стили (`src/css/`)

`main.css` импортирует по порядку: шрифты → `tokens.css` (цвета, шрифты, размеры, `--lattice`) → `base.css` → `components.css` → `header.css` → `chrome.css` (плавающие кнопки, футер, переходы, курсор, тост) → `sections.css` → `scene.css` → `calc.css` → `booking.css` → `pages.css`.

Фирменные цвета (только через переменные): `--orange #E85002`, `--orange-hot #F16001`, `--red #C10801`, `--sand #D9C3AB`, `--white #F9F9F9`, `--gray-light #A7A7A7`, `--gray #646464`, `--gray-dark #333`; градиент `--grad-brand` (#D9C3AB → #F16001 → #C10801 → #000).

### Правила дизайна (выстраданные)

- **Не использовать `text-indent`** на заголовках с `data-split` — с разбиением по словам он рвёт строки. Смещение заголовка делается колонками сетки.
- **Без `text-shadow`/свечения на тексте внутри `data-split`** — маски SplitText обрезают свечение в прямоугольник.
- **Контурный текст** (`-webkit-text-stroke`) у Unbounded показывает внутренние линии шрифта → использовать `paint-order: stroke fill` + заливку цветом фона.
- Не трогать глобальное правило `prefers-reduced-motion` в `base.css`: бегущая строка намеренно работает на JS, чтобы ехать и при reduced motion.
- В сетках на мобильных — `minmax(0, 1fr)`, а не `1fr` (иначе длинные слова/кнопки раздувают колонку).
- Раздел «Главная»: заголовки секций по центру (`align: 'center'`, `label: false`); на внутренних страницах — смещённые с подписью «(01) …».
- На каждой странице на экране не больше одной кнопки «Записаться».

## 6. Стиль кода

- Чистый JS (ES-модули), без TypeScript и фреймворков. Vite 7, GSAP 3.15 (ScrollTrigger, SplitText), Lenis 1.3, Barba 2.10, Three r180.
