# CLAUDE.md

Полное руководство по проекту для ИИ-агентов — в `AGENTS.md` (подключено ниже). Документация для владельца — `README.md`.

Коротко о главном:
- Общение с владельцем, тексты сайта и комментарии в коде — **на русском**.
- **Не выдумывать факты** — только плейсхолдеры `[ЦЕНА]`, `[ОПИСАНИЕ]` и т.п.
- Страницы генерируются из `content/*.json` + `src/templates/**` (HTML-файлов страниц нет). После серии правок шаблонов при ошибке «X is not defined» — перезапусти dev-сервер.
- Эффекты проверять с `?motion=1` (у владельца включено «уменьшение движения»).
- Перед завершением — `npm run build` без ошибок.
